# To Do List

A single-user application for grouping units of work into named lists and tracking which ones are finished.

## Language

**List**:
A named group of tasks.
_Avoid_: folder, collection, category, project, group

**Task**:
A single unit of work that belongs to exactly one list.
_Avoid_: todo, item, entry, job

**Completed**:
The state of a task whose work is finished. The opposite of Open.
_Avoid_: done, finished, checked, closed

**Open**:
The state of a task whose work is not finished yet. The opposite of Completed.
_Avoid_: pending, active, unfinished, in progress

**Due date**:
An optional point in time by which a task is expected to be completed. It affects the order in which tasks are read; it never blocks anything.
_Avoid_: deadline, due time
